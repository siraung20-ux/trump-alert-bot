# Trump X Tracker Telegram Bot

Donald Trump ၏ X (Twitter) post များကို track လုပ်ပြီး Telegram Channel သို့ auto-post လုပ်ပေးမည့် Bot ဖြစ်ပါသည်။

## Features
- **Real-time Monitoring**: ၅ မိနစ်တစ်ကြိမ် အလိုအလျောက် စစ်ဆေးပေးခြင်း။
- **AI Summary**: OpenAI GPT-4 သုံးပြီး post များကို အကျဉ်းချုပ်ပေးခြင်း။
- **Auto-Post**: Telegram Channel ထဲသို့ လှပသော format ဖြင့် ပို့ပေးခြင်း။

## Setup
1. `pip install -r requirements.txt` ကို run ပြီး လိုအပ်သည်များ install လုပ်ပါ။
2. `trump_tracker_bot.py` ထဲတွင် သင်၏ API Key များကို ဖြည့်ပါ။
3. `python trump_tracker_bot.py` ဖြင့် run ပါ။
